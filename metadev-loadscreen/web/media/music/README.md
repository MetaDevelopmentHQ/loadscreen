# web/media/music

Put your music files here (`.mp3` or `.ogg`) and add them to the playlist in
the editor (`/loadscreen` → Media) as `media/music/your-song.mp3`.

- Only use music you have the rights to.
- New files are sent to players only after a resource restart
  (`ensure metadev-loadscreen`), because FiveM packs resource files at start.
- Remote files work too: use an `https://` link that does not expire
  (not Discord CDN links).

---

Müzik dosyalarını (`.mp3` veya `.ogg`) buraya koy ve editörde (`/loadscreen` →
Medya) playlist'e `media/music/sarki-adi.mp3` şeklinde ekle. Yeni dosyalar
oyunculara ancak resource yeniden başlatılınca gider. Sadece hakkına sahip
olduğun müzikleri kullan.
